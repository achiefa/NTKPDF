Data and analysis resources
===========================

These provider modules connect loss ingredients, NTK eigensystems and report
outputs. ``NTKStats.data`` includes a leading replica axis; ``NTKStats.shape``
describes the observable without that axis. Keep PDF-grid dimensions distinct
from model-parameter dimensions when interpreting matrix shapes.
