API reference
=============

The pages below use autodoc on the code on disk. Signatures expose Python
arguments; in registered provider modules those same names are reportengine
dependencies. Config production methods are requested without their
``produce_`` prefix. Private helpers are implementation details, not a stable
runcard interface.
