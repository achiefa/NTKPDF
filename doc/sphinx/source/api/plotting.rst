Plotting
========

The drawing layer accepts Stats-like objects independently of the observable.
PDF orchestration works with validphys ``XPlottingGrid`` objects. Report
providers declare dependencies and return figures through reportengine
decorators. Feature-spectrum wrappers adapt colibri's plotting interface.
